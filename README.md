# Reverse Turing Test AI Project (AlibAi)

This project started as a reverse Turing-test but evolved into a murder-mystery style game (where you play as the killer) and your goal is to trick AI characters into blaming each-other consistently enough such that you escape justice and are able to murder everyone. 

The game centers around the fact that everyone except you has a real Alibi each night, you must solely rely on your ability to deceive and deflect in order to escape the gallows. Each character has their own memory, don't know who is AI and who is human, and will remember what happened each night in order to form suspicions and alliances. For example, if Jerry and Dave spent the night in the same room they will vouch for each other (perhaps a good idea to take one of them out so they can't gang up on you later).

The project uses OpenAI's ChatGPT API to generate character text, decide the conversational flow, condense/summarise the conversation for the agents, and decide how each character will vote at the end of rounds.

It should be noted that while billed as a "game" the application itself is missing some core gameplay features and thus it functions closer to a proof-of-concept or demo, it is more of a personal project than a fully fledged title and is best regarded as such.
