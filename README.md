# Reverse Turing Test AI Project

This project uses multiple large language models (LLMs) via APIs to build a reverse Turing test.

If you would like to run this project I recommended downloading it for free via Steam:
https://store.steampowered.com/app/3325660/AlibAi/

This will allow the program to be run without needing an API key.

It should be noted that while billed as a "game" the application itself is missing some core gameplay features and thus it functions closer to a proof-of-concept or demo, it is more of a personal project than a fully fledged title and is best regarded as such.
